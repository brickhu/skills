# 好组件库全是 React 写的，我用 Vue/Solid/Svelte 怎么办？——recomp，把任意组件库文档复刻成你的 headless 组件

> 开源技能 recomp 推广｜仓库：https://github.com/brickhu/skills

---

做前端这么多年，我有个体会：

**前端不缺组件库，缺的是"你能用的"组件库。**

打开 GitHub 和各大文档站，组件库多到挑花眼：shadcn/ui、Radix、MUI、Ant Design……质量一个比一个高，设计一个比一个精致。可当你兴冲冲地把代码复制到自己的项目里，问题就来了——

**你用的是 SolidJS / Vue / Svelte，而这些组件库，几乎全是 React 写的。**

你可能会说：框架不匹配，那抄样式总行了吧？

真做了才知道——

- **框架对不上**：JSX、hooks、受控组件，复制过来直接报错。React 的组件 API 没法原样搬到 Vue / Solid / Svelte
- **样式对不上**：就算框架一样，组件库用 Tailwind 写的，你的项目用的是 StyleX / CSS-in-JS，class 满天飞，照样没法用
- **设计对不上**：组件库自带一套设计 token，跟你的设计系统打架，改起来比重写还累
- **行为最麻烦**：就算全都对上了——焦点陷阱、键盘交互、ARIA 无障碍、边缘情况，这些"行为层"的东西，自己写一个能跑，写对很难

最后的结果就是：看着满屏的好组件，你只能安慰自己"写业务功能要紧"，然后继续手搓轮子。

## 换个思路：组件库的本质是什么？

**一个组件 = 行为层 + 视觉层。**

- **行为层**：状态、键盘交互、焦点管理、无障碍 ARIA——下拉框怎么用方向键选、弹窗怎么锁住焦点、日期选择器怎么处理边界情况
- **视觉层**：颜色、间距、圆角、阴影——也就是你的设计 token 和样式

你真正缺的，往往是**行为层**。而视觉层，本来就该由你的设计系统说了算——别人的样式，永远是你的"参考"，不该是"全部"。

这个思路有个现成的名字：**headless 组件**——行为归组件，样式归你，中间通过 data-attribute、class 插槽、CSS 变量对接。

`recomp` 就是干这个的。它是开源的 AI 技能包，装上之后，你的 AI 编程助手就变成你的**组件复刻外包**：

| 本来要自己啃的 | 现在发个链接就行 |
|---|---|
| 通读 React 组件源码，理解行为逻辑 | 把组件文档 URL 发给 recomp |
| 对照 WAI-ARIA 规范补全无障碍 | 自动按规范补全，并标注"哪部分按规范补的" |
| 把 JSX 翻译成 Vue / Svelte / Solid 惯用法 | 按你的框架生成：Vue 用 v-model、Svelte 5 用 bind/runes、Solid 用 signal |
| 研究焦点陷阱、键盘交互怎么实现 | 行为契约摘要直接列给你看 |
| 担心复刻质量没底 | 决策记录逐条标注：哪些来自文档、哪些按规范补全、哪些留给你拍板 |

**样式和设计 token 完全归你。** recomp 交付的是纯行为组件 + 样式接口契约（data-attribute 全集、class 插槽、CSS 变量），你复制源码、接上自己的样式，完事。不满意某个行为？直接在对话里说，它把完整文件重出给你——不用打补丁，复制粘贴即可。

## 你担心：AI 复刻的东西，能信吗？

放心，这正是 recomp 最花心思的地方——复刻最容易出问题的几个环节，它都给你上了保险：

- **不是组件库页面？拒绝。** 你发的是博客、工具库、设计稿，它直接拒绝并说明原因，绝不硬着头皮"猜着复刻"
- **无障碍语义绝不瞎猜。** ARIA 角色、焦点管理、键盘行为，要么按 WAI-ARIA APG 规范补全（并标注），要么明确告诉你"这块没实现"，宁可留白不做假
- **不碰你的工程。** 探测你的框架、CSS 方案、设计 token 时只读——不建目录、不改文件，探测结果只用于本次复刻，用完即弃
- **生态里已有的，不重复造轮子。** Solid 用 Kobalte、Vue 用 Reka UI、Svelte 用 Bits UI——你生态里已有等价物，它直接推荐你用现成的，不浪费你的时间
- **许可边界分明。** 复刻的是"接口 + 行为"，不抄别人的源码和样式值，来源记录留档，商用也安心

一句话：**AI 负责搬运和复刻，接口、行为、边界全都在你手里。**

## 怎么装？怎么用？

**安装（一行命令）：**

```sh
# 路径里的 /recomp 就是技能名，无需再加 -s
npx skills add brickhu/skills/recomp
```

支持任何能加载 SKILL.md 的 AI 编程助手（Claude Code、Cursor、Zed 都行）。也可以手动把 recomp 文件夹复制到你的技能目录。

**用法（三步）：**

1. **发链接**：把组件库文档页 URL 发给它（比如 shadcn/ui 的 Dialog 文档）
2. **审契约**：它会先给你一份"行为契约摘要"——接口、行为、决策记录，你确认没问题再看代码
3. **复制即用**：源码按文件输出在对话里，复制进你的组件目录，接上你的样式，完事

**不满意？直接改。** "escape 处理不对""这里用 bind 不要用 v-model"——它当场重出完整文件，直到你满意为止。
