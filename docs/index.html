What are recipes?

Recipes turn frequent multi-step operations — generating an invite code, running a weekly report — into a single trigger phrase. They live in .dbops/recipes.json (project-level) or ~/.dbops/recipes.json (global).

How to configure

  1. Copy the JSON of a recipe you like — from the cards below or the Gallery page.
  2. Paste it into your agent chat and say "add this recipe" — preview it, confirm, done.
  3. When asked, bind the recipe's connection to one of your whitelisted connections (shared recipes use the YOUR_DB placeholder).

You can also edit .dbops/recipes.json by hand — each entry is plain JSON.
